# Svar om föreningen

`opensverige.yaml` är svaren Fråga kartan visar när någon frågar om föreningen OpenSverige. Svaret visas ordagrant, med källa och datum.

## Var svaren kommer ifrån

Varje svar bygger bara på sidan i `kalla_url`. `kontrollerad` är dagen den sidan lästes. Ändras sidan ska svaret och datumet ändras här.

En människa godkänner varje nytt svar innan det går in.

`npm run validera` kontrollerar filen.
